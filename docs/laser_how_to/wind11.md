# Windows 11 Upgrade Guide for LASER Users

## Overview

The LASER Virtual Machines (VMs) have now been upgraded to **Windows 11**.

All existing users have been migrated from the legacy Windows 10 environment to Windows 11. As part of this migration:

- Users will need to **create or recreate their working environments**.
- Software applications may need to be **launched, configured, or reinstalled** through AppsAnywhere.
- User-specific settings and local customisations from the previous Windows 10 VM may need to be recreated.

> **Important:** Project data has not been affected by the upgrade.

All project data stored on the **Project N Drive** remains available and the existing project folder structure and file paths have not changed.
It is recommended that project data be stored on N Drive at all times, and avoid storing important project data on local VM desktop folders, or other local locations.

---

# Accessing Software Using AppsAnywhere

Most approved software is available through **AppsAnywhere**.

## Step 1 - Open AppsAnywhere

From your Windows 11 VM:

1. Open the **Browser**.
2. Navigate to **https://appsanywhere.leeds.ac.uk/login**.
3. Launch the AppsAnywhere portal and login with your UoL credentials when prompted.

You should see the AppsAnywhere home page.  
![appsanywhere_luanch.png](../images/wind11/appsanywhere_luanch.png)

---

## Step 2 - Navigate to LASER Approved Applications

From the left-hand menu:

1. Select **All Apps**.
2. Under **Categories**, select **LASER Approved**.

Only applications approved for use within the LASER are displayed.
![appsanhwere_laser_how_to.png](../images/wind11/appsanhwere_laser_how_to.png)

## Step 3 - Launch an Application

Locate the software you require and select **Launch**.

The application will then:

- Download any required components (if needed).
- Configure the software.
- Start the application.

Some applications may take a few minutes to launch the first time they are used.

![Available Apps](../images/wind11/appanywhere_laser_available_apps.png)

---

## Step 4 - Configure Your Environment

Because this is a new Windows 11 environment, you may need to:

- Reconfigure software preferences.
- Set up Artificatory
- Recreate Python or Conda environments.
- Reinstall required packages and libraries.
- Reconfigure R packages.

---

# If an Application is Unavailable

Some applications may display an **Unavailable** message.

Possible reasons include:

- The software requires additional approval.
- The software licence is restricted.
- The application is not available within the LASER environment.
- Additional prerequisites are required.

If the software is required for your research project, contact the dat@leeds.ac.uk.
